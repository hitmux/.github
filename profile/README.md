# Countless Ways, Boundless Intelligence

*Beyond my reach, yet ever the longing of my heart*

**Software freedom in the age of AI.**

Everyone should be able to run software, study how it works, adapt it to their needs, and share copies and improvements. We publish source code and documentation so people can exercise those freedoms in practice.

## Our principles

- **Software freedom.** We use clear licenses so people know what they can do with the software and share with others.
- **Open to scrutiny.** We document how our software works and why we made key design decisions so others can verify its behavior and propose improvements.
- **Long-term maintainability.** We document how to build, test, and release our software so others can maintain it or continue the work in a fork.

As AI changes how software is built, we want developers to retain the ability to understand, modify, and control the tools they rely on.
